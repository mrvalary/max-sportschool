# MAX Mini App — спортивно-адаптивная школа

Статическое мини-приложение для публикации на GitHub Pages и открытия внутри WebView MAX.

## Файлы
- `index.html` — интерфейс приложения
- `styles.css` — адаптивное оформление + тёмная тема
- `script.js` — навигация, направления и FAQ

## Публикация на GitHub Pages
1. Откройте Settings → Pages.
2. Source: `Deploy from a branch`.
3. Branch: `main`, folder: `/ (root)`.
4. Сохраните.
5. Адрес проекта: `https://mrvalary.github.io/max-sportschool/`.

## CRM / форма
Кнопка «Перейти к форме обращения» временно ведёт на существующую страницу Mavibot:
`https://mavibot.site/st/c112/`

Это сохраняет уже проверенную цепочку формы → CRM → этап «Заявка получена» → метка «Обращение» → уведомление администрации.

## Перед финальной публикацией
- добавить официальный логотип и фотографии;
- сверить точный адрес организации;
- перенести точные тексты FAQ и населённые пункты;
- добавить ссылку на политику обработки персональных данных.
