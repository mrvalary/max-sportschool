# MAX Mini App — ХКСАШПСР

Обновлённая версия мини-приложения для GitHub Pages и открытия внутри MAX.

## Что изменено
- переработан главный экран;
- фотографии вынесены в аккуратную галерею с едиными пропорциями;
- направления оформлены карточками с иконками и метками, без визуального перегруза;
- улучшены контакты, блок обращения и экран «Об организации»;
- сохранена совместимость с действующей формой Mavibot.
