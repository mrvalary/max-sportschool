# MAX Mini App — ХКСАШПСР

Статическое мини-приложение для MAX, опубликованное через GitHub Pages.

## Данные
Контент актуализирован по официальному сайту школы `kski.ru`:
- Ресурсный центр: 14 дисциплин, 40 групп, 3 территории;
- адрес, контакты и график работы;
- цели организации;
- фотографии загружаются с официального сайта `kski.ru`.

## Технологии
- HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

## CRM
Кнопка «Открыть форму» временно ведёт на действующую форму Mavibot:
`https://mavibot.site/st/c112/`

Так сохраняется проверенная цепочка: форма → CRM → этап «Заявка получена» → метка «Обращение» → уведомление администрации.
